# Using the side panels and metadata

The sidebar in Mirador provides contextual information and navigation tools for the active object.

## Info panel

- Review the descriptive metadata for the current object.
- Find labels, summaries, and general information about the resource.
- Use the info panel when working with catalog and collection-level descriptions.

## Attribution panel

- Review rights statements, provider information, and attribution details.
- Confirm who owns or provides the resource and how it may be reused.
- Use attribution information when evaluating licensing or citation requirements.

## Annotations panel

- Open the annotations panel to review annotation sets and visible comments.
- Understand how annotation layers appear and which sets are in use.
- Use filters to narrow the view to the most relevant annotations.

## Search panel

- Open the search panel to look for terms across the manifest or dataset.
- Review search results and jump to relevant canvases or regions.
- Search-driven navigation is especially useful with long manuscripts or structured objects.

## Layers panel

- Switch between image layers or alternative views when available.
- Inspect layer choices for manuscripts, maps, or complex digital objects.
- Use the layers panel to understand which alternative image service is active.

## Understanding panel controls

- Each panel may include actions for expand, collapse, filter, or alternate view.
- Panel controls help users focus on metadata or navigation without losing the image context.
- Learn the panel behavior of a resource before relying on it for repeated workflows.
