# Language, locale, and appearance settings

Mirador can be configured to support different interface languages, themes, and reading patterns.

## Switching languages

- Use the interface language settings to change the viewer labels.
- Some manifests may also include language-specific metadata or labels.
- A locale change affects the interface, not necessarily the underlying resource description.

## Dark mode and light mode

- Switch between darker and lighter interface themes for comfort or accessibility.
- Appearance settings can support different reading environments and user preferences.
- Good contrast is important for readability and accessibility.

## Right-to-left language support

- Mirador supports right-to-left reading patterns when the resource or interface metadata requires it.
- Resource metadata, `viewingDirection`, and locale settings can influence how the viewer behaves.
- This is especially useful for languages and materials that are normally read right to left.
