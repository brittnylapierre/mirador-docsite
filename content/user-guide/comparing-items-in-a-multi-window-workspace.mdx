# Comparing items in a multi-window workspace

Mirador is designed for comparing related objects or pages across multiple windows.

## Opening multiple windows

- Open additional windows to compare different resources or canvases.
- Add new manifests or existing resources into separate windows for side-by-side work.
- Use the workspace controls to manage the number of active windows.

## Comparing side by side

- Place related objects next to each other for close comparison.
- Keep the most relevant windows visible while reducing visual clutter.
- Compare editions, manuscripts, maps, or other related objects in parallel.

## Arranging workspace layout

- Reposition windows to fit the current comparison task.
- Adjust how windows are laid out depending on the number of materials in view.
- Use the workspace arrangement best suited to the project or reading workflow.

## Using mosaic vs elastic mode

- Mosaic mode provides a structured arrangement with predictable grid-like organization.
- Elastic mode allows more flexible manual positioning for a less rigid workspace.
- Choose the layout that supports the comparison task without distracting from the content.

## Maximizing, focusing, and closing windows

- Maximize a single window to inspect one object in detail.
- Focus on the active window for more controlled navigation and browsing.
- Close windows when they are no longer needed in the current comparison task.

## Typical use cases

- Compare two manuscripts from different institutions.
- Place a map side by side with a catalog record or related image.
- Review manuscript pages while keeping metadata or annotations visible in separate panels.
