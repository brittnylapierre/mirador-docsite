# Opening and loading a IIIF object

This page explains how to start working with a IIIF resource inside Mirador.

## Adding a manifest by URL

- Paste a IIIF manifest URL into the add-resource flow.
- Confirm the resource loads successfully before moving on to viewing and navigation.
- If the URL is invalid or the resource is not available, Mirador will not be able to render the object.

## Loading a collection

- Open a IIIF collection to browse related manifests or sub-collections.
- Use the collection hierarchy to move between items without leaving the viewer.
- A collection is useful when a project groups related resources by theme, exhibition, or research set.

## Adding resources to the workspace

- Add one or more resources from the workspace controls.
- Open multiple objects for comparison, reading, or structured research workflows.
- Keep track of which resource is active, especially in multi-window layouts.

## Understanding a manifest vs canvas vs sequence

- A manifest is the IIIF resource description that defines the object and its structure.
- A canvas is the individual page, image, or media unit that is displayed in a window.
- A sequence is the ordered set of canvases or pages associated with a manifest.
- In simple terms: manifest -> sequence -> canvas.

## Best practices

- Start with a known-good manifest URL before testing complex collections.
- Check whether the resource is a manifest, collection, or media object.
- Use the viewer’s structure information to understand how pages are organized.
