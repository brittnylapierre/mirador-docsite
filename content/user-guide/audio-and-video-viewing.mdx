# Audio and video viewing

Mirador can also display IIIF resources that include audio or video.

## Playing embedded media

- Use the media playback controls to start, pause, seek, and adjust volume.
- The viewer behaves like a standard browser media player when the resource includes time-based media.
- Playback depends on the manifest structure and browser support.

## Basic controls and browser behavior

- Media controls may vary depending on the browser and the embedded resource.
- Some resources may require specific media encodings or browser support to play correctly.
- If the media does not play, check the resource configuration and browser environment.

## Differences between image and media manifests

- Image manifests focus on static canvases and zoomable views.
- Media manifests include time-based content and play controls rather than image navigation alone.
- The interface should adapt based on whether the resource is static, media-based, or mixed.

## Best practice

- Use the resource’s metadata and media controls to understand available playback and navigation options.
- Confirm that the manifest is valid and that the browser supports the media type.
