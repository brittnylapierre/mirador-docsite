# Searching and finding content

Mirador supports IIIF search workflows when the manifest provides the necessary search service.

## Searching within a manifest

- Open the search panel to search for text or terms in the resource.
- Search results depend on a valid IIIF Content Search service being present in the manifest.
- If no search service is available, the feature will not appear or will not return results.

## Reading results

- Review the search result list in the sidebar.
- Understand which canvas or segment contains the match and how it is categorized.
- Results often include snippet text or metadata that helps interpret the match.

## Jumping to matching canvases

- Select a result to jump directly to the matching canvas or region.
- Use result navigation to move quickly through a long object or text-heavy resource.
- This workflow saves time compared with manual page-by-page scanning.

## Using search-driven navigation

- Search can act as a structured path through the resource.
- Use it to locate specific references, names, dates, or terms.
- This is especially helpful for manuscripts, archival materials, and richly indexed resources.

## Good practice

- Confirm the manifest includes a searchable text layer or content search service.
- Use the sidebar results to understand whether the match is on the current page or elsewhere in the resource.
