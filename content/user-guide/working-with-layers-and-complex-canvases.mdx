# Working with layers and complex canvases

Some IIIF resources include multiple image layers, alternative sequences, or complex page structures.

## Switching image layers

- Use the layers panel to change the active image layer.
- Different layers may show different views or brighten, restore, or emphasize details.
- Layer changes are most useful for manuscripts, maps, and objects with multiple image treatments.

## Handling sequence variants

- Some resources contain multiple sequences or alternative reading orders.
- Switch between sequences to review different page arrangements or material groupings.
- Sequence variants may reflect the original object structure or a curated presentation order.

## Working with layered, manuscript, or map content

- Manuscripts may include complex arrangements with folios, alternative views, or folded structures.
- Maps may add comparison or layered image treatments for interpretation.
- Use the viewer controls to focus on the most important structure for the current task.

## When to use book vs scroll vs single mode

- Book view is effective for facing pages or paged objects.
- Scroll view is better for long continuous reading sequences.
- Single view is ideal for focused inspection of one page at a time.

## Suggested workflow

1. Open the layers panel.
2. Check whether the resource has multiple image layers or sequences.
3. Choose a reading mode that matches the object structure.
4. Use the canvas or thumbnail navigation to move through the resource.
