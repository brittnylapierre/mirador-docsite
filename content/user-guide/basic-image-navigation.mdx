# Basic image navigation

This page covers the core actions used to inspect an image in Mirador.

## Zoom, pan, and rotate

- Use zoom controls to inspect details and then reset to the default view.
- Pan around the image to move across the canvas without changing the zoom level.
- Rotate the image when the resource or viewer supports it and the image orientation requires adjustment.

## Using thumbnails and canvas navigation

- Move between canvases using the thumbnail strip or related navigation controls.
- Use a thumbnail view to scan the resource quickly and jump to specific pages or images.
- The current canvas and thumbnail selection should stay in sync.

## Switching between canvases and sequences

- Move forward and backward through the resource using the canvas controls.
- If a manifest contains multiple sequences, switch between them when needed.
- Sequence navigation is especially useful for manuscripts, multi-part documents, or alternative reading orders.

## Using single, book, scroll, and gallery views

- Single view: best for focused reading of one canvas at a time.
- Book view: useful for facing pages or spread-based structures.
- Scroll view: useful for continuous reading of long material.
- Gallery view: best for browsing many thumbnail images quickly.

## Practical workflow

1. Open a manifest.
2. Choose the best display mode for the material.
3. Zoom and pan to study details.
4. Use thumbnails or canvas navigation to move through the object.
